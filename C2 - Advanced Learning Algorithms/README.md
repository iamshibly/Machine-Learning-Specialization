## What this course covers

- **Neural Networks:** Neurons, dense layers, activation functions, and inference; Building neural networks using NumPy and TensorFlow; Binary recognition with a handwritten-digit classification exercise.
- **Neural Networks Training:** Training neural networks for multiclass classification; ReLU and softmax activation functions; TensorFlow workflows for digit-recognition experiments.
- **Advice for Applying Machine Learning:** Bias, variance, underfitting, and overfitting; Train, validation, and test splits and model evaluation; Iteration strategies for improving generalization.
- **Decision Trees:** Decision-tree splits and information gain; Tree-based prediction and controlling overfitting; Ensemble methods, including random forests and boosted trees.
